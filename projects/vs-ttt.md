## Overview

This is a mod for [DELTARUNE](https://deltarune.com/), which uses [Kristal](https://kristal.cc/). Kristal is made using [LÖVE](https://love2d.org/), which is a framework for making 2D games in Lua.

This project was as a hands‑on way to learn Lua and working with an already established codebase. I explored Kristal's world, battle, and cutscene systems, modified attack patterns, wrote custom dialogue, and integrated a new music track. For the audio I remixed the [original song](https://www.youtube.com/watch?v=UQbIvweE3ng) into an intense battle theme. The mod was well received; it was downloaded several hundred times.
